# Nuadyr-mpv

A fork of [mpv-android](https://github.com/mpv-android/mpv-android) with a better non-player UI. The player itself is unchanged.

## What's different

- **Android TV home screen:** a grid of thumbnails for every video and audio file on the device, with no buttons.
- Phones and tablets still use the original home screen.

## Using it on a TV

- **OK** plays a file.
- **Menu**, or press and hold **OK**, opens the extra options: Open URL, Browse folders and Settings.

## Building

Builds run in GitHub Actions. Push a commit, then download the APK from the workflow run.
